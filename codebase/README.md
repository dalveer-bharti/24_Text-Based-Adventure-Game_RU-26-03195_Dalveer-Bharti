# 24_Text-Based-Adventure-Game_RU-26-03195_Dalveer-Bharti
A console-based Python 3 game built using functions, loops, conditions, and the random module. Starting in a forest with 100 Health and 0 Score, the player chooses between exploring a cave (facing a monster attack and finding a key for +20 score) or a river (finding treasure for +50 score). The game continues until the player decides to quit or their health reaches 0.
<b>A Python 3 text-based adventure game where the player explores a forest, cave, and river, faces random monster attacks, and collects score</b>
